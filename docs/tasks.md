## 2. 技术方案总结

### 2.1 音频系统技术方案
**推荐方案**: speaker + lame
- **speaker**: 原生音频输出库，直接访问系统音频设备
- **lame**: MP3编码解码库，处理音频格式转换
- **优势**: 维护活跃、跨平台、性能优秀、稳定可靠

**备选方案**: 
- web-audio-api (最高兼容性)
- audio-play (最轻量级)

### 2.2 视频系统技术方案
**Canvas渲染策略**: 使用 node-canvas 作为中间层
- **优势**: 最小化代码修改、保持渲染逻辑、灵活输出、渐进开发
- **渲染流程**: 游戏逻辑 → Canvas绘制 → 像素数据 → {PNG文件/字符画}

**ANSI颜色转换**: 支持 ansi16、ansi256、rgb 三种模式
- **ansi256**: 推荐方案，216色立方体 + 灰度色
- **RGB转换公式**: `16 + (36 * Math.round(r/51)) + (6 * Math.round(g/51)) + Math.round(b/51)`

### 2.3 Node.js原生改造原则
- **彻底移除**: window、document、Canvas、Web Audio API、DOM Events 等
- **使用原生**: fs模块、EventEmitter、Buffer、原生音频库等
- **不追求**: Web兼容性、保持原有API
- **专注于**: 纯Node.js实现、性能优化、最佳实践

## 6. 使用示例

### 6.1 基础使用
```bash
# ASCII模式（默认）
gbajs2 game.gba

# PNG模式
gbajs2 game.gba --renderer png --output ./frames

# 同时输出
gbajs2 game.gba --renderer both --color

# 仅测试Canvas渲染
gbajs2 game.gba --test-canvas --renderer png
```

### 6.2 高级配置
```bash
# 自定义ASCII尺寸
gbajs2 game.gba --ascii-width 100 --ascii-height 30

# 16色字符画 (兼容性最佳)
gbajs2 game.gba --color --color-mode ansi16

# 256色字符画 (推荐)
gbajs2 game.gba --color --color-mode ansi256

# 真彩色字符画 (最新终端)
gbajs2 game.gba --color --color-mode rgb

# 高帧率测试
gbajs2 game.gba --fps 60 --renderer both

# 检测终端颜色支持
gbajs2 game.gba --detect-colors
```
