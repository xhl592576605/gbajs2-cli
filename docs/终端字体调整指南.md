## 终端字体调整指南

为了让 CLI 在 240×160 分辨率下尽量“点对点”显示，需要终端提供尽可能多的列/行。终端默认字体尺寸较大时，一行只能容纳 120~150 列，会迫使渲染器把多个像素合并成同一个字符，因此会出现马赛克或黑边。手动调低字体是目前最有效的办法。不同终端的设置入口如下：

### macOS Terminal.app / iTerm2 / Warp
| 终端 | 操作路径 |
| --- | --- |
| **Terminal.app** | `设置 (Settings)` → `Profiles` → 选择当前 profile → `Text` → `Font`，把字号调小（例如 12→10 或更低）。 |
| **iTerm2** | `Preferences` (`⌘,`) → `Profiles` → 选定 profile → `Text` → `Font`（或 `Size` slider），建议使用等宽字体并把字号降低。 |
| **Warp** | 右上角 `Settings` → `Appearance` → `Font Size`，可在 10~11 之间反复调整直到终端列数 ≥ 220。 |

### Kitty / WezTerm / Alacritty
| 终端 | 操作路径 |
| --- | --- |
| **Kitty** | 编辑 `~/.config/kitty/kitty.conf`，设置 `font_size 10.0`（或更小），保存后 `kitty @ set-font-size`/重启生效。 |
| **WezTerm** | `~/.wezterm.lua` 中设置 `font_size = 10.0` 并保存，重启终端即可。 |
| **Alacritty** | `alacritty.yml` → `font: size: 10.0`，保存后重启。 |

### Windows Terminal / 其他
| 终端 | 操作路径 |
| --- | --- |
| **Windows Terminal** | `Settings` → 选择 profile → `Appearance` → `Font face` & `Font size`，调低 `Font size`（例如 10pt）。 |
| **VS Code integrated terminal** | `Settings` → 搜索 `terminal.integrated.fontSize`，将值调至 `10` 或更小。 |

### 提示策略
当前 CLI 会在状态栏中提示 auto-fit 结果，例如 `auto-fit 120×38` 或 `终端需 ≥ 240×80 字符`。当看到“终端需 ≥ …”时，请在对应终端里按上表操作减小字体/扩大窗口，直至提示消失。程序默认使用 256 色输出，以兼容所有主流终端。
