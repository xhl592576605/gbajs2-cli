## 🎉 项目概览

**gbajs2-cli** 是一个将浏览器版 GBA 模拟器改造为 Node.js 原生命令行工具的项目。

### 核心特性
- ✅ 纯 Node.js 实现，无浏览器依赖
- ✅ 命令行界面，支持多种参数
- ✅ PNG 图片序列输出
- ✅ 终端字符画实时显示
- ✅ 原生音频输出支持
- ✅ 跨平台兼容（Windows/macOS/Linux）

### 技术亮点
- 使用 Canvas 作为渲染中间层
- 支持 ANSI 多种颜色模式（16/256/真彩色）
- speaker + lame 音频解决方案
- 完整的 GBA 硬件模拟
